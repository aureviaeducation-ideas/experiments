# 🧭 Aurus — National & State Entrance Exam Tracker

Aurus is a light, fast, and privacy-first Web Application and Progressive Web App (PWA) designed to track application deadlines, status, and custom notes for major Indian entrance exams (Engineering, Medical, State CETs, Management, and Private Universities).

---

## 📱 How to Access & Install Aurus

### 🌐 Live Web App
Access the live application directly in any modern browser:
👉 **[Launch Aurus App](https://aureviaeducation-ideas.github.io/experiments/aurus/)**

---

### 📲 Install as an App on Mobile & Desktop

Aurus works as a **Progressive Web App (PWA)**, meaning you can install it directly onto your device without downloading anything from the Play Store or App Store.

#### 🤖 Android (Google Chrome / Brave / Edge)
1. Open the [Live Aurus App Link](https://aureviaeducation-ideas.github.io/experiments/aurus/) in Chrome.
2. Tap the **three dots menu (⋮)** in the top-right corner.
3. Select **Add to Home Screen** or **Install App**.
4. Confirm by tapping **Add**. The Aurus icon will appear on your home screen and open in full-screen mode.

#### 🍎 iPhone / iPad (Safari)
1. Open the [Live Aurus App Link](https://aureviaeducation-ideas.github.io/experiments/aurus/) in Safari.
2. Tap the **Share button** (the square with an arrow pointing up).
3. Scroll down and tap **Add to Home Screen**.
4. Tap **Add** in the top-right corner.

#### 💻 Windows / Mac (Chrome or Edge)
1. Open the [Live Aurus App Link](https://aureviaeducation-ideas.github.io/experiments/aurus/).
2. Click the **Install icon** (monitor with an arrow) on the right side of the browser address bar (or go to `Menu → Save and share → Install page as app`).

## ✨ Features
- 📅 **Chronological Timeline View:** Month-by-month tracking from October/November through April/May.
- 🎯 **Category & State Filters:** Easily switch between National Engineering, State CETs, Management/MCA, and Private Varsity exams.
- 🔔 **Dynamic Status Indicators:** Automatic badges for Active, Closing Soon, and Expired/Closed forms.
- 🔒 **100% Privacy & Offline Support:** All user tracking data and custom notes are stored locally in your browser (`localStorage`). No tracking or external databases.
- 📄 **PDF & Print Export:** Print or download clean PDF status summaries directly from the dashboard.
- 💾 **JSON Backup & Share:** Export your custom exam database and share it across devices.

---

## 🔒 Privacy Disclaimer
Aurus does not collect, track, or transmit any user data. Exam dates, opening/closing ETAs, and links are compiled from public web searches and official exam portals. Candidates should verify all final details on the respective official university/conducting body websites.
